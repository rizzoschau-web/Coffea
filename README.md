# Coffea — Landing Page

## Descripción

Coffea es una landing page estática para una cafetería ficticia, desarrollada como parte del trabajo práctico de Diseño UX-UI.

El objetivo del proyecto es reproducir el diseño de referencia de Figma utilizando HTML5 y CSS3, cuidando la organización del contenido, la estética visual, la accesibilidad y la adaptación a distintos tamaños de pantalla.

## Tecnologías utilizadas

- **HTML5:** estructura semántica del sitio.
- **CSS3:** estilos, diseño visual y animaciones de interacción.
- **Flexbox y CSS Grid:** organización y distribución de los elementos.
- **CSS Custom Properties:** variables para colores, tipografías y espaciados.
- **Media Queries:** adaptación del diseño a dispositivos móviles, tablets y computadoras.
- **Netlify:** publicación del sitio web.

## Secciones de la página

La landing page está compuesta por las siguientes secciones:

1. Header y navegación.
2. Hero principal.
3. Categorías de café.
4. Productos destacados: café.
5. Productos destacados: postres.
6. Sección promocional de granos de café.
7. Testimonios de clientes.
8. Newsletter.
9. Footer con enlaces y redes sociales.

## Características

- Diseño inspirado en una cafetería moderna.
- Maquetación con HTML semántico.
- Estilos organizados mediante CSS.
- Diseño responsive para diferentes resoluciones.
- Interacciones implementadas con CSS, sin JavaScript.
- Navegación y controles con foco visible.
- Carruseles con desplazamiento horizontal y scroll-snap.
- Organización de estilos mediante variables y componentes reutilizables.

## Cómo ejecutar el proyecto localmente

1. Clonar el repositorio o descargar los archivos.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Abrir el archivo `index.html` en el navegador, o utilizar la extensión Live Server.
4. Verificar que los estilos y las imágenes se carguen correctamente.

No se necesita instalar dependencias ni ejecutar un servidor backend.

## Publicación

El sitio se publica en Netlify como una página estática.

La configuración de despliegue utiliza la raíz del proyecto como directorio de publicación. El repositorio se conecta con Netlify para permitir actualizaciones automáticas al subir cambios a la rama `main`.
